# 成长空间

一个可以慢慢看见自己变化的地方。

不是课程平台，也不是测评工具 —— 它先让你**认识自己**，再**随手记下一点**，
然后**看见自己确实走过**，最后才在你真的想往下走的时候，给一个方向。

**不是心理测评，也不替代任何专业帮助。** 所有内容都只在你自己的浏览器里。

## 怎么打开

直接用浏览器打开 `index.html` 即可，无需安装、无需联网、无需服务器：

```
双击 index.html（推荐 Chrome / Edge）
```

手机上想体验：把整个 `growth-space` 文件夹拷到手机，用浏览器打开里面的 `index.html`。

> 省事版：根目录的 **`成长空间.html`** 是「单文件版」，CSS/JS 已全部内联，一个文件即完整 App。
> 用微信/QQ 发给手机 → 手机上点开 → 选「用浏览器打开」即可，不用管文件夹结构。

打开后可以直接用 `#页码` 深链接，例如 `index.html#trace` 打开成长轨迹、
`成长空间.html#explore` 打开探索。认不出的页码会落回首页。

### iPhone / iPad

「添加到主屏幕」之后会按全屏 App 打开（不是塞在 Safari 外壳里），用的是
`icon-180.png` 那个自绘的主屏图标。

**发文件给 iPhone 是不可靠的**：微信里的 `.html` 要经「用文件打开」才进得去，
Safari 从「文件」App 打开本地网页时 LocalStorage 还可能被整个禁用 ——
那种情况下 App 不会崩（所有存储访问都包了 try/catch），但**写了也存不住**。
想让朋友稳定看到，用网址（GitHub Pages）最稳；纯本地的话，示例模式那条路
反而是完整的，因为它根本不用存储。

## 五个入口

| 入口 | 做什么 |
|---|---|
| **首页** | 问候 + 15 题入口（已完成则变成回看）+ 最近的成长记录 + 6 个探索方向；宽屏右栏是「今日小记 / 我的心情 / 近期学习」 |
| **成长轨迹** | 把你做过的事按时间摆出来，分「今天 / 昨天 / 9月14日」；只呈现，不打分、不排名、不算「进步了多少」 |
| **记录** | 今日小记 + 我的心情（近 14 天曲线）+ 全部记录 |
| **探索** | 6 个需求入口 + 九个成长方向地图 + 可以开始的课 |
| **我的** | 我的画像（15 题生成的《第一次认识自己》）、收藏、设置（昵称 / 提醒 / 数据） |

下钻页（无底栏，靠返回键）：`questionnaire`（15 题）、`record`（记录详情）、
`zone`（区域详情）、`topic`（方向详情）、`lesson`（课程学习）、`nickname`（首次问称呼）。

**首页的成长记录是「摘要」，成长轨迹是「全量」。** 心情每天都能记，小记和课程
不是，所以首页那 8 条里心情最多占 2 条（`timelineItems(8, {maxMood: 2})`），
其余位置让给完成课程、写下的话、画像 —— 否则记得越勤，首页越被
「心情 · 还不错」这种没有内容的行占满，两节已完成的课反而看不见。
**成长轨迹不设任何上限，一条不删。**

## 15 题 · 第一次认识自己

「最近的你，还好吗？」10 道日常自我观察 + 3 道情境 + 2 道开放填空，约 5 分钟。

- 点选项就直接进下一题；最后两题可以留空跳过，**跳过不等于失败**。
- 进度用「03 / 15」和一条细线，不用粗百分比条 —— 那会把这件事变成「完成任务」。
- 选完不立刻给反馈，**没有对错、没有分数、没有类型**。
- 完成后生成一条记录《第一次认识自己》（我最近的状态 / 我最近最想改变的 /
  我比较在意的事情 / 我注意到的自己 / 我想继续了解的方向 / 我写给未来自己的话），
  它同时是「成长轨迹」的第一个节点，可以点回去看。
- 方向由简单规则映射（情绪反应 / 关系沟通 / 行动习惯 / 自我接纳 / 思维认知），
  多个方向接近时会说「似乎同时在关注几个方向」，**不强行给单一结论**。
- 课程入口只在**完成之后**出现，而且只是「可以继续看的方向」。

## 九个成长方向

`js/data/regions.js` 的 9 个区全部渲染在「探索」页，中央区（自我认知与反应）可学习，
其余显示「即将开放」。**这是框架占位，不是内容上线。**

现有 5 节课都在中央区，内容一字未改。

## 示例模式

给「刚打开、还不知道这是干嘛的」的人一条路：称呼页的**先看看示例**、
以及首页空状态里的同一个入口。

进去之后是一份「用了十来天」的数据 —— 有记录、有轨迹、有心情曲线、有画像。
点得动：心情可以选、小记可以写。

**但它一个字节都不写进 LocalStorage。** 读写全部改道到一份内存副本
（拦截点在 `js/core/store.js` 的 `loadJson` / `saveJson`，整个 App 只有这一个
存储出入口，所以拦一次十个页面就都进了示例模式）。因此：

- 朋友在里面怎么点，都不会留下痕迹，更不会覆盖他自己的真实数据
- 刷新即退出（标志是模块变量，不落盘）
- 顶部有一条深色横幅写着「这些不是你写的内容」，右边是「开始写我自己的」

数据在 `js/data/demo.js`，日期一律相对今天算，所以哪天打开都是新鲜的。
`tools/shot.js` 的截图种子也用这一份，不再另抄 —— 抄本会漂移，
而「截图里看到的样子」和「朋友点开看到的样子」必须是同一个东西。

## 数据与隐私

- 所有输入（答案、小记、心情、反思、收藏、设置）只保存在**你自己的浏览器**里
  （LocalStorage，前缀 `gs.`）。没有账号、不上传、不同步。
- 换一台设备、换一个浏览器，这里就是空的 —— 这是「纯本地」的代价，不是 bug。
- 想清空重来：按 `F12` 打开控制台，输入 `devReset()` 回车。
  页面里也可以：「我的 → 关于数据 → 清空所有数据」。
- **提醒做不到真提醒**：这个网页没有后台，关掉之后不会再运行，
  所以设置里的提醒只会在你打开页面时温和地提一句。UI 文案是照实说的。

## 开发

纯 HTML / CSS / JavaScript，**零第三方依赖**，只用浏览器和 Node 内置模块。

```
index.html          入口（三栏外壳：左侧栏 / 主区 / 右栏）
app.js              启动：migrate → Router.init → 首屏落点（认 location.hash）
css/style.css       全部样式（移动端优先，断点 900 / 1180）
js/core/            ui · icons · store(LocalStorage) · router(路由) · widgets(共享组件)
js/data/            regions(9区) · courses(课程) · questionnaire(15题) · record(画像生成)
                    topics(6 个探索入口) · demo(示例数据)
js/pages/           home · trace · notes · explore · me · questionnaire · record
                    topic · zone · lesson · nickname
icon-180.png        主屏图标（由 tools/icon.js 算出，不是素材文件）
tools/              build-single(单文件构建) · smoke(浏览器冒烟测试)
                    mobile(真手机宽度溢出检查) · shot(截图) · shots/(截图产物)
                    demotest(示例模式) · icon(主屏图标)
```

代码风格是 **ES5**：全 `var`、字符串 `+` 拼接、IIFE + `window.XXX`。
不用箭头函数、模板字符串、`const/let`、`Object.assign/entries`、`includes`、`padStart`。

### 构建单文件版

```
node tools/build-single.js          生成「成长空间.html」
node tools/build-single.js --check   只校验磁盘上的产物是否最新（退出码 0/1）
```

产物是 **UTF-8 带 BOM**，内联块前后是 CRLF，正文是 LF（沿用历史版本的形态，
所以构建脚本可以用「逐字节一致」来做正确性验证）。

### 验证

```
node tools/smoke.js                 跑真实浏览器的冒烟测试（205 条断言 × 3 个视口）
node tools/smoke.js "成长空间.html"  对单文件版跑同一套断言
node tools/mobile.js                真手机宽度下的横向溢出检查（默认 390）
node tools/mobile.js 390 375 414    指定多个宽度
node tools/demotest.js              示例模式：进出流程 + 【全程不写 LocalStorage】
node tools/icon.js                  重新生成 icon-180.png
node tools/shot.js all              截图到 tools/shots/（会先验证路由真的落对了页）
node tools/shot.js demo             截示例模式的样子（带顶部横幅）
```

三个工具都在项目根目录生成临时页，**跑完自己删掉**（它们会被一起推到 GitHub Pages）。

`tools/smoke.js` 会真的开 Chrome 跑 `index.html`，覆盖命名空间加载、导航生成、
15 题全流程、记录生成与回看、时间轴、9 区地图、老数据兼容、切页滚动复位。
注意它的视口由 `--window-size` 设定，而 **Chrome 在 Windows 上有最小窗口宽度
（实测 ~487px）**，所以「手机端无横向滚动」这条在它那里其实是在 487px 下验的。

`tools/mobile.js` 补的就是这个缺口：把页面套进 `width=390` 的 iframe，
里面的文档才会真的按 390 排版。它同时断言每页顶栏标题 —— 少了这一条，
干净的 profile 会让 `boot()` 每次都先跳「称呼」页，六个页面量到的是同一页，
还全部 PASS（只看 `scrollWidth` 永远发现不了）。

`tools/shot.js` 截图前会先 `--dump-dom` 逐页确认渲染出来的确实是那一页 ——
截图工具自己会撒谎（曾经 18 张图里 15 张是首页却全报 ✓），所以让它自证。
它截图时也套 iframe，理由同上。

### 三个已经踩过的坑，别再踩

1. **别只读属性，要读实际样式。** `tools/demotest.js` 第一版判断横幅在不在，
   读的是 `b.hidden`。而 CSS 里写了 `#demoBar{display:flex}` —— 作者样式盖过
   浏览器默认的 `[hidden]{display:none}`，于是属性是 `true`、横幅却全程占着
   46px 显示着，断言还报 PASS。现在读 `getBoundingClientRect().height > 0`。
   **凡是 `[hidden]` 的元素自己又写了 `display`，都必须补一条 `[hidden]{display:none}`。**

2. **标记要在运行时拼。** `--dump-dom` 会把 `<script>` 源码一起吐出来，
   写死的标记字符串会匹配到源码而不是输出。也别顺手塞进 `document.title` ——
   那样它同样是 DOM 里的字面量，而且出现在最前面，正则会从那儿开始吃。

3. **Windows 上 `--dump-dom` 的行尾是 CRLF。** 比较前先 `.replace(/\r/g, "")`，
   否则「成长轨迹」和「成长轨迹」比不相等，肉眼完全看不出来。
