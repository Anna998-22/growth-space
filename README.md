# 成长空间

一个温和的个人成长小工具原型。帮自己留意「下意识反应」、理解情绪、练习先停一下。**不是心理测评或治疗产品**，只是一个每天 5–10 分钟的自助练习工具。

## 怎么打开

直接用浏览器打开 `index.html` 即可，无需安装、无需联网、无需服务器：

```
双击 index.html（推荐 Chrome / Edge）
```

手机上想体验：把整个 `growth-space` 文件夹拷到手机，用浏览器打开里面的 `index.html` 也行。

> 省事版：根目录的 **`成长空间.html`** 是"单文件版"，CSS/JS 已全部内联，一个文件即完整 App。
> 用微信/QQ 发给手机 → 手机上点开 → 选「用浏览器打开」即可，不用管文件夹结构。

## 现在能玩什么（第一阶段）

一个完整的成长闭环：

**首次进入 → 成长状态自评（5 题）→ 基础成长画像 → 首页 → 今日课程 → 学习 → 今日练习 → 反思 → 保存记录 → 完成课程 → 成长档案 / 阶段复盘**

- **5 节真实课程**（约 5–10 分钟／节），都在「自我认知与反应」区：
  1. 《我为什么总是下意识地这样反应？》
  2. 《看见自己的自动化反应》
  3. 《情绪出现时，我真正发生了什么？》
  4. 《从"马上反应"到"先停一下"》
  5. 《复盘：我正在重复什么模式？》
- **9 区成长路线**已就位，中央区可学习，其余区域暂时显示「即将开放」——只作框架占位，不让结构缺失。
- **练习记录与成长档案**都存在浏览器本地（LocalStorage），别人看不到，清除浏览器数据才会消失。

## 数据与隐私

- 所有输入（画像、练习笔记、反思、成长记录）只保存在**你自己的浏览器**里。
- 想清空重来：在页面里按 `F12` 打开控制台，输入 `devReset()` 回车，再刷新即可。

## 目录结构

```
index.html          入口
app.js              启动逻辑（首次进入 → 自评 → 首页）
css/style.css       全部样式（移动端优先）
js/core/            ui / store(本地存储) / router(页面路由)
js/data/            regions(9区) / assessment(自评) / courses(课程)
js/pages/           首页 · 路线 · 课程 · 练习 · 档案 · 自评 · 课程学习
```

纯 HTML / CSS / JavaScript，零第三方依赖。直接双击可用。
